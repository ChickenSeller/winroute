Proxifier's features, in a new app

Rules per application

Match by program (name, path or wildcard), target host, IP range or port, and send the connection through a proxy, directly, or block it. Rules apply from top to bottom.

SOCKS and HTTPS proxies

SOCKS4, SOCKS4A, SOCKS5 with a username and password, and HTTPS proxies with CONNECT and Basic authentication, over IPv4 and IPv6.

Proxy chains

Go through several proxies one after another, fall back to the next when one fails, or spread connections over them at random.

Name resolution through the proxy

Let the proxy resolve host names, so the local network never sees them, and write rules by host name even when programs connect by IP.

Live connections and traffic

Every connection with its program, target, rule and bytes, a traffic graph, per-program statistics and a log. Disconnect a connection or end its process in one click.

Proxifier profiles

Reads and writes Proxifier's .ppx files and imports your Proxifier profile on the first start. Switch between profiles from the tray.

Proxy checker

Test a proxy or a whole chain: the connection to it, a connection through it and an HTTP request, step by step.

English, Chinese and Japanese

The app, its log and the installer follow the Windows language, or the one you pick.

How it works

No program is changed and nothing is injected into it. A network driver catches each new connection before it leaves the machine, and WinRoute decides where it goes.

  1. Catch The NetFilter SDK WFP driver reports every outgoing TCP connection, with the program that opened it.
  2. Decide The first rule that matches the program, host and port picks the action: a proxy, a chain, direct, or block.
  3. Redirect Proxied connections are pointed at WinRoute's local relay; direct ones go on untouched.
  4. Tunnel The relay talks SOCKS or HTTPS to the proxies, then passes the data through and counts it.

WinRoute's own connections are never caught, and a connection to one of your proxies goes direct, so traffic cannot loop.

Build from source

Needs Qt 6 (MinGW, 64-bit), CMake 3.21 and the NetFilter SDK with a signed netfilter2.sys, which are not part of the repository. Inno Setup 6 builds the installer.

git clone %PROJECT_URL%.git
cd winroute
# put the NetFilter SDK in netfilter/ and the driver in netfilter2.sys
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=<Qt dir>
cmake --build build
cmake --build build --target installer
