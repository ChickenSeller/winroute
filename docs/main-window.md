# 主窗口

主窗口上部为若干标签页，下部为[日志](./log)。

## 工具栏

| 按钮 | 功能 |
| --- | --- |
| 上游代理 | 管理代理服务器和代理链，参见[上游代理](./proxies) |
| 代理规则 | 编辑规则，参见[代理规则](./rules) |
| 域名解析 | 设置域名在本地解析或由代理解析，参见[域名解析](./dns) |
| 代理网关 | 使其他设备经由本机访问网络，参见[代理网关](./gateway) |
| 断开连接 | 关闭所选连接 |
| 结束进程 | 结束所选连接所属的进程 |
| 结束进程树 | 结束所选连接所属的进程及其所有子进程 |
| 代理检测 | 测试代理服务器是否可用，参见[代理检测](./checker) |
| 抓包 | 打开抓包页，参见[抓包](./capture) |

## 连接

列出当前经过 WinRoute 的所有连接。单击列标题可排序。

![连接列表](/images/connections.png){width=1103}

上图中，curl.exe 匹配“命令行工具”规则，经由本机的代理客户端（127.0.0.1:10808）连接；代理客户端 python.exe 自身的连接由[连接环路检测](./advanced#连接环路检测)自动改为直接连接。

| 列 | 内容 |
| --- | --- |
| 应用程序 | 程序名称和进程 ID |
| 目标 | 目标主机和端口。应用程序按 IP 地址连接时，尽可能显示对应的域名 |
| 协议 | TCP 或 UDP，以及 IPv4 或 IPv6 |
| 时间/状态 | 连接持续时间，或正在连接、失败等状态 |
| 规则 : 代理 | 匹配的规则，以及所用代理的地址或代理链 |
| 发送 / 接收 | 数据量 |

代理网关运行时，其他设备经由网关建立的连接也显示在此列表中，应用程序一列显示为 `[Gateway] 设备 IP`。

右键单击连接可执行以下操作：

- **断开连接**：立即关闭该连接。
- **结束进程**：结束发起该连接的进程，执行前会要求确认。WinRoute 先关闭该进程的窗口，使其像用户关闭时一样正常退出；5 秒内未退出，或该进程没有窗口时，则强制结束。
- **结束进程树**：结束发起该连接的进程，以及它的所有子孙进程，过程与“结束进程”相同。适合结束会派生出多个子进程的程序。
- **为此应用程序创建规则...**：以该应用程序为条件新建规则。
- **复制**：复制连接信息。

::: info 直接连接不显示的原因
默认情况下，匹配“直接连接”规则的连接不经过 WinRoute，因此不显示在列表中。如需显示，请启用[处理直接连接](./advanced#处理直接连接)。
:::

## 流量

![流量图](/images/traffic.png){width=1103}

显示实时流量曲线：

- 本机的下行速率和上行速率各一条曲线。
- 代理网关运行时，另显示网关的下行速率和上行速率曲线。

图表上方的图例按组排列，每组下行在上、上行在下，显示当前速率和自清除以来的最高速率。单击图例可显示或隐藏对应曲线。单击 **清除** 可清空曲线并重新累计总量。

## 统计

按应用程序和目标汇总连接数、活动连接数、发送量、接收量和最近活动时间，并在 **状态** 列显示该应用程序当前是 **运行中** 还是 **已结束**。右键单击可 **复制** 或 **重置统计**；对运行中的应用程序，还可 **结束进程** 或 **结束进程树**。

## 抓包

在 **工具 > 抓包** 中启用后显示此标签页，参见[抓包](./capture)。

## 状态栏

显示活动连接数、当前速率、拦截后端、驱动状态和当前配置文件。
