# 主窗口

主窗口上半部分是几个标签页，下半部分是[日志](./log)。

## 工具栏

| 按钮 | 作用 |
| --- | --- |
| 上游代理 | 管理代理服务器和代理链，见[上游代理](./proxies) |
| 代理规则 | 编辑规则，见[代理规则](./rules) |
| 域名解析 | 设置域名在本地还是由代理解析，见[域名解析](./dns) |
| 代理网关 | 让其他设备经本机上网，见[代理网关](./gateway) |
| 断开连接 | 关闭选中的连接 |
| 结束进程 | 结束选中连接所属的程序 |
| 代理检测 | 测试代理是否可用，见[代理检测](./checker) |
| 抓包 | 打开抓包页，见[抓包](./capture) |

## 连接

列出当前所有经过 WinRoute 的连接。点列标题可以排序。

![连接列表](/images/connections.png){width=1103}

上图中，curl.exe 命中“命令行工具”规则，经本机的代理客户端（127.0.0.1:10808）连接；代理客户端 python.exe 自己的连接被[连接环路检测](./advanced#连接环路检测)自动改为直连。

| 列 | 内容 |
| --- | --- |
| 应用程序 | 程序名和 PID |
| 目标 | 目标主机和端口。程序按 IP 连接时，会尽量显示对应的域名 |
| 协议 | TCP 或 UDP，以及 IPv4 或 IPv6 |
| 时间/状态 | 连接持续的时间，或正在连接、失败等状态 |
| 规则 : 代理 | 命中的规则，以及使用的代理地址或代理链 |
| 发送 / 接收 | 流量 |

代理网关开启时，其他设备经网关的连接也会出现在这里，应用程序一栏显示为 `[Gateway] 设备IP`。

在连接上点右键：

- **断开连接**：立即关闭这个连接。
- **结束进程**：结束发起这个连接的程序，会先确认。
- **为此应用程序创建规则...**：以这个程序为条件新建一条规则，不用手动输入程序名。
- **复制**：复制连接信息。

::: info 直连的连接为什么看不到
默认情况下，命中“直接连接”规则的连接不经过 WinRoute，所以不会出现在列表里。需要看到它们时，开启[处理直接连接](./advanced#处理直接连接)。
:::

## 流量

![流量图](/images/traffic.png){width=1103}

实时流量曲线：

- 本机的下行、上行速率各一条线。
- 代理网关运行时，另有网关的下行、上行两条线。

图上方的图例按组排列，每组下行在上、上行在下，显示当前速率和清除以来的最高速率。点击图例可以显示或隐藏对应的线。**清除** 按钮清空曲线，并重新开始累计总量。

## 统计

按应用程序和目标汇总：连接数、活动连接、已发送、已接收、最近活动时间，便于找出流量最大的程序。右键可以 **复制** 或 **重置统计**。

## 抓包

在 **工具 > 抓包** 打开后才会出现这个标签页，见[抓包](./capture)。

## 状态栏

显示活动连接数、当前速率、拦截后端和驱动状态。
