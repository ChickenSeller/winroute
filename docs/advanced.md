# 高级选项

这些选项都在 **配置文件 > 高级** 菜单里，随配置文件保存。

## HTTP 代理服务器

启用后，才能在[上游代理](./proxies)里添加 HTTP 协议的代理。HTTP 代理只能用于 HTTP 连接（浏览器等），不要和 HTTPS 代理混淆。

## 服务和其他用户

默认只处理当前用户运行的程序。可以额外勾选：

- **Windows 服务和其他系统进程**
- **此计算机上其他用户运行的应用程序**

::: info
这些选项只影响 TCP 和 UDP。ping、tracert 这类 ICMP 流量无论如何都不能走代理。
:::

## 处理直接连接

- **关闭**（默认）：命中“直接连接”规则的连接完全不经过 WinRoute，不显示、不统计，开销最小。
- **开启**：直连的连接也经过 WinRoute，会出现在连接列表里，计入流量和统计，也可以被[抓包](./capture)。

规则[指定了网卡](./rules#指定网卡)的直连连接总会经过 WinRoute。

## 连接环路检测

防止连接绕圈子，建议保持开启：

- 连接的目标正好是代理服务器本身时，改为直连。
- 代理服务器在本机时（例如监听 `127.0.0.1:1080` 的代理客户端），监听这个端口的程序自己发出的连接会自动直连，不会再被送回它自己。

检测到时，日志里会对每个进程提示一次。

## 通过 SOCKS5 转发 UDP

默认 UDP 直接放行。开启后，命中规则且动作是 **单个 SOCKS5 代理** 的 UDP（如游戏、语音通话）通过 SOCKS5 的 UDP ASSOCIATE 转发。

- 代理链或 SOCKS4、HTTPS 代理不支持 UDP，会直连，并在日志中提示一次。
- 代理不支持 UDP 时也会回退为直连。可以先用[代理检测](./checker)看看代理是否支持 UDP。

## 在日志中显示 DNS

在日志中记录 DNS 查询，排查域名规则时有用。

## 密码加密

选择代理密码在配置文件里的保存方式：

| 方式 | 说明 |
| --- | --- |
| 禁用 | 明文保存，任何能读取配置文件的人都能看到密码 |
| Basic | 用 WinRoute 的固定密钥加密，任何人用 WinRoute 打开这个配置文件都能使用密码 |
| 当前用户账户 | 用当前 Windows 用户的登录凭据加密，只有当前用户能使用 |

主密码方式暂不支持。
