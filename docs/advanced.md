# 高级选项

以下设置位于 **配置文件 > 高级** 菜单中，随配置文件保存。

## HTTP 代理服务器

启用后，可在[上游代理](./proxies)中添加 HTTP 协议的代理服务器。HTTP 代理仅可用于 HTTP 连接（如浏览器），请勿与 HTTPS 代理混淆。

## 服务和其他用户

默认仅处理当前用户运行的应用程序。可另外勾选：

- **Windows 服务和其他系统进程**
- **此计算机上其他用户运行的应用程序**

::: info
这些设置仅影响 TCP 和 UDP。ping、tracert 等使用的 ICMP 协议无法经由代理转发。
:::

## 处理直接连接

- **未启用**（默认）：匹配“直接连接”规则的连接不经过 WinRoute，不显示、不统计，开销最小。
- **启用**：直接连接也经过 WinRoute，显示在连接列表中，计入流量和统计，并可被[抓包](./capture)记录。

规则[指定了网卡](./rules#指定网卡)时，其直接连接始终经过 WinRoute。

## 连接环路检测

防止连接形成环路，建议保持启用：

- 连接目标为代理服务器本身时，改为直接连接。
- 代理服务器位于本机时（例如监听 `127.0.0.1:1080` 的代理客户端），监听该端口的进程自身发出的连接将自动直接连接，不会再次被转发给它自己。

检测到环路时，日志中对每个进程提示一次。

## 通过 SOCKS5 转发 UDP

默认情况下 UDP 直接放行。启用后，匹配规则且操作为 **单个 SOCKS5 代理** 的 UDP 流量（如游戏、语音通话）通过 SOCKS5 的 UDP ASSOCIATE 转发。

- 代理链、SOCKS4 和 HTTPS 代理不支持 UDP，相应流量将直接连接，并在日志中提示一次。
- 代理服务器不支持 UDP 时同样改为直接连接。可使用[代理检测](./checker)确认代理服务器是否支持 UDP。

此为全局默认设置，可在规则中单独覆盖，参见[代理规则 > UDP](./rules#udp)。

## 在日志中显示 DNS

在日志中记录 DNS 查询，便于排查基于域名的规则。

## 密码加密

设置代理密码在配置文件中的保存方式：

| 方式 | 说明 |
| --- | --- |
| 禁用 | 以明文保存，任何可读取配置文件的人均可获取密码 |
| Basic | 使用 WinRoute 的固定密钥加密，任何人使用 WinRoute 打开该配置文件均可使用密码 |
| 当前用户账户 | 使用当前 Windows 用户的登录凭据加密，仅当前用户可使用 |

暂不支持主密码方式。
