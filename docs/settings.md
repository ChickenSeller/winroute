# 界面、托盘与更新

## 视图菜单

| 菜单项 | 作用 |
| --- | --- |
| 工具栏、状态栏 | 显示或隐藏 |
| 刷新频率 | 连接列表和流量图的刷新速度。越慢越省资源 |
| 在系统托盘显示图标 | 见下文 |
| 语言 | 简体中文、日本語、English。默认跟随系统，切换后重启生效 |

## 系统托盘

开启 **在系统托盘显示图标** 后：

- 关闭主窗口只是把它隐藏到托盘，WinRoute 继续工作；
- 托盘图标的提示里显示当前配置、活动连接数和速率；
- 托盘菜单可以打开主窗口或退出。

要真正退出，用 **文件 > 退出** 或托盘菜单的退出。

## 更新

在 **帮助** 菜单里：

| 菜单项 | 作用 |
| --- | --- |
| 检查更新... | 立即检查新版本。确认后自动下载、校验并安装，完成后 WinRoute 自动重启 |
| 通过代理检查更新... | 本机直连无法访问更新服务器时，选择配置里的一个代理来检查和下载 |
| 自动更新 | 自动安装所有更新、自动安装必须的更新、更新前询问，或从不检查 |

下载的安装包会校验 SHA-256，损坏的文件不会被安装。

## 匿名使用统计

**帮助 > 发送匿名使用统计**：帮助改进 WinRoute，不包含个人数据，可以随时关闭。

## 关于

**帮助 > 关于 WinRoute** 显示版本号。
