# 界面、托盘与更新

## 视图菜单

| 菜单项 | 功能 |
| --- | --- |
| 工具栏、状态栏 | 显示或隐藏 |
| 刷新频率 | 连接列表和流量图的刷新频率。频率越低，资源占用越少 |
| 在系统托盘显示图标 | 参见下文 |
| 语言 | 简体中文、日本語、English。默认跟随系统设置，切换后须重新启动程序 |

## 系统托盘

启用 **在系统托盘显示图标** 后：

- 关闭主窗口时仅将其隐藏到系统托盘，WinRoute 继续运行；
- 托盘图标的提示信息显示当前配置文件、活动连接数和速率；
- 托盘菜单可打开主窗口或退出程序。

如需退出程序，请使用 **文件 > 退出** 或托盘菜单中的退出命令。

## 更新

**帮助** 菜单提供以下更新相关命令：

| 菜单项 | 功能 |
| --- | --- |
| 检查更新... | 立即检查新版本。确认后自动下载、校验并安装，完成后 WinRoute 自动重新启动 |
| 通过代理检查更新... | 无法直接访问更新服务器时，选择配置文件中的代理进行检查和下载 |
| 自动更新 | 可选择自动安装所有更新、自动安装必需的更新、更新前询问或从不检查 |
| 自动更新 > 通过代理检查 | 自动检查和下载更新时通过代理进行，而非直接连接。适用于无法直接访问更新服务器的网络；所用代理为配置文件的默认 DNS 代理，没有则为第一个代理 |

下载的安装程序经 SHA-256 校验，校验失败的文件不会被安装。

## 匿名使用统计

**帮助 > 发送匿名使用统计**：用于改进 WinRoute，不包含个人数据，可随时关闭。

## 关于

**帮助 > 关于 WinRoute** 显示版本信息。
