# 代理链

代理链在 **上游代理** 窗口的下半部分管理。

## 创建代理链

1. 单击 **创建**，输入代理链名称。
2. 将上方列表中的代理 **拖放** 到代理链中。链中的顺序即使用顺序，在链内拖动可调整顺序。
3. 取消勾选链中代理前的复选框，可暂时停用该代理。
4. 选择代理链，单击 **类型...** 设置其工作方式。

![上游代理窗口下半部分为代理链](/images/proxies.png){width=563}

代理链创建后，可与单个代理一样在[规则](./rules)中用作操作。

## 代理链类型

![代理链类型](/images/chain-type.png){width=343}

### 简单链

连接依次经过链中的每个代理服务器：先连接第一个代理，再经由它连接第二个代理，依此类推，最后由最后一个代理连接目标主机。适用于需要多级转发的场合。

### 冗余

优先使用第一个代理；连接失败时改用下一个，依此类推。单击 **选项...** 可设置以下各项：

![冗余选项](/images/redundancy.png){width=344}

| 选项 | 说明 |
| --- | --- |
| 连接代理超时（秒） | 连接单个代理的等待时间，超时即视为失败 |
| 重新检测失败代理的间隔（秒） | 失败的代理在此期间被跳过，之后重新尝试 |
| 所有代理都失败时直接连接 | 未勾选时连接失败；勾选后改为直接连接 |
| 重置所有代理的失败状态 | 使已失败的代理立即重新参与 |

### 负载均衡

每个连接随机选用一个代理。

勾选 **同一进程 PID 使用同一个代理** 后，同一进程的连接固定使用同一代理。部分网站在出口 IP 地址变化时会要求重新登录，此选项可避免该问题。

::: info
代理链仅转发 TCP。UDP 只能经由单个 SOCKS5 代理转发；匹配代理链的 UDP 流量将直接连接，并在日志中提示一次。
:::
