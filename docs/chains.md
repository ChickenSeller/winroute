# 代理链

代理链在 **上游代理** 窗口的下半部分管理。

## 创建代理链

1. 点 **创建**，输入链的名称。
2. 把上面代理列表里的代理 **拖进** 链中。链中的顺序就是使用顺序，在链内拖动可以调整顺序。
3. 用代理前的复选框可以临时停用链中的某个代理。
4. 选中链，点 **类型...** 选择链的工作方式。

![上游代理窗口下半部分是代理链](/images/proxies.png){width=563}

创建后，代理链和单个代理一样，可以在[规则](./rules)里作为动作使用。

## 链的类型

![代理链类型](/images/chain-type.png){width=343}

### 简单链

依次经过链中的每个代理：先连第一个代理，再通过它连第二个……最后由最后一个代理连接目标。适合需要多跳的场景。

### 冗余

先用第一个代理，失败了换下一个，依此类推。点 **选项...** 可以设置：

![冗余选项](/images/redundancy.png){width=344}

| 选项 | 说明 |
| --- | --- |
| 连接代理超时（秒） | 等待一个代理多久就算失败 |
| 重新检测失败代理的间隔（秒） | 失败的代理在这段时间内被跳过，之后再重试 |
| 所有代理都失败时直接连接 | 不勾选时连接会失败；勾选后改为直连 |
| 重置所有代理的失败状态 | 让失败的代理立即重新参与 |

### 负载均衡

每个连接随机挑一个代理。

勾选 **同一进程 PID 使用同一个代理** 后，同一个程序的连接固定走同一个代理。有些网站会因为出口 IP 变化而要求重新登录，这个选项可以避免这种情况。

::: info
代理链只转发 TCP。UDP 只能经单个 SOCKS5 代理转发，命中代理链的 UDP 会直连，并在日志中提示一次。
:::
