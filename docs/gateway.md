# 代理网关

工具栏：**代理网关**。

代理网关让 WinRoute 本身成为一个 HTTP 和 SOCKS5 代理服务器。局域网里的其他设备（手机、电视、游戏机、虚拟机、其他电脑）把代理设成这台电脑，就能经它上网，并使用本机的代理和代理链。

## 设置

![代理网关窗口](/images/gateway.png){width=563}

### 启用

勾选 **开启代理功能，让其他机器通过本机访问网络**。这是整个功能的总开关。

### 监听

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 地址 | `0.0.0.0` | 监听哪块网卡，默认所有网卡。只想给某个网段用时，选那块网卡的地址 |
| HTTP 端口 | 8080 | HTTP 代理，支持 CONNECT 和普通 HTTP 请求。可单独关闭 |
| SOCKS5 端口 | 1080 | SOCKS5 代理。可单独关闭 |

### 认证

填写用户名和密码后，客户端必须认证：SOCKS5 用用户名密码认证，HTTP 用 Basic 认证。

用户名留空则允许匿名使用。

::: warning
匿名网关在同一网络里的任何人都能用，只建议在可信的家庭网络里这样做。
:::

### 出站连接

| 方式 | 说明 |
| --- | --- |
| 遵循本机的代理规则 | 按本机的[代理规则](./rules)处理。远程连接没有本地进程，按应用程序区分的规则会被跳过 |
| 全部走指定的代理或代理链 | 所有连接都走选定的出口 |
| 始终直接连接 | 不经任何代理，直接出网 |

选择“全部走指定的代理或代理链”时，**当所选代理无法连接时** 可以选：

- **阻止**：拒绝连接，保证流量不会悄悄绕过代理；
- **直接连接**：改为直连。

## 在其他设备上使用

以本机局域网 IP 是 `192.168.1.10` 为例：

- **HTTP 代理**：服务器 `192.168.1.10`，端口 `8080`。手机的 Wi-Fi 设置里一般就是这种。
- **SOCKS5 代理**：服务器 `192.168.1.10`，端口 `1080`。

::: tip 连不上？
- 检查 Windows 防火墙是否允许外部访问这两个端口。
- 确认设备和本机在同一网段，并且路由器没有开启“AP 隔离”。
- 查看日志，看看是否有来自这台设备的连接记录或认证失败。
:::

## 查看网关流量

- **连接列表**：网关的连接显示为 `[Gateway] 设备IP`。
- **流量图**：网关运行时多出网关的下行、上行两条线。
- **日志**：写明每个连接经过的规则和网卡。
- **抓包**：勾选 **抓取：代理网关** 即可记录；还可以[解密 HTTPS](./https#解密代理网关上的设备)。
