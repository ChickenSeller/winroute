# 代理网关

工具栏：**代理网关**。

代理网关使 WinRoute 作为 HTTP 和 SOCKS5 代理服务器运行。局域网内的其他设备（手机、电视、游戏机、虚拟机、其他计算机）将代理服务器设为本机后，即可经由本机访问网络，并使用本机配置的代理和代理链。

## 设置

![代理网关窗口](/images/gateway.png){width=563}

### 启用

勾选 **开启代理功能，让其他机器通过本机访问网络**。此项为该功能的总开关。

### 监听

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 地址 | `0.0.0.0` | 监听的网卡地址，默认为所有网卡。如仅供特定网段使用，请输入对应网卡的地址 |
| HTTP 端口 | 8080 | HTTP 代理，支持 CONNECT 和普通 HTTP 请求。可单独停用 |
| SOCKS5 端口 | 1080 | SOCKS5 代理。可单独停用 |

### 出站连接

| 方式 | 说明 |
| --- | --- |
| 遵循本机的代理规则 | 按本机的[代理规则](./rules)处理。远程连接没有本地进程，按应用程序设置的规则将被跳过 |
| 始终直接连接 | 不经由任何代理，直接访问网络 |
| 全部走指定的代理或代理链 | 所有连接均经由所选代理或代理链 |

选择“全部走指定的代理或代理链”时，可在 **当所选代理无法连接时** 中选择：

- **阻止**：拒绝连接，确保流量不会绕过代理；
- **直接连接**：改为直接连接。

### 身份验证

输入用户名和密码后，客户端须进行身份验证：SOCKS5 使用用户名/密码认证，HTTP 使用 Basic 认证。

用户名留空时，允许客户端无需验证即可使用。

::: warning
未设置身份验证时，同一网络中的任何设备均可使用该网关。建议仅在可信的网络中使用此方式。
:::

## 在其他设备上使用

以本机局域网 IP 地址 `192.168.1.10` 为例：

- **HTTP 代理**：服务器 `192.168.1.10`，端口 `8080`。手机 Wi-Fi 设置中的代理通常为此类型。
- **SOCKS5 代理**：服务器 `192.168.1.10`，端口 `1080`。

::: tip 无法连接时
- 确认 Windows 防火墙允许外部设备访问上述端口。
- 确认设备与本机位于同一网段，且路由器未启用 AP 隔离。
- 在日志中确认是否有来自该设备的连接记录或身份验证失败的记录。
:::

## 查看网关流量

- **连接列表**：网关连接显示为 `[Gateway] 设备 IP`。
- **流量图**：网关运行时显示网关的下行和上行曲线。
- **日志**：记录每个连接所匹配的规则和使用的网卡。
- **抓包**：勾选 **抓取：代理网关** 即可记录，并可[解密 HTTPS](./https#解密代理网关设备)。
