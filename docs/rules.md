# 代理规则

菜单：**配置文件 > 代理规则...**，或工具栏的 **代理规则**。

![代理规则窗口](/images/rules.png){width=863}

## 匹配顺序

每个新连接从上到下依次比对规则，由 **第一条命中** 的规则处理，后面的规则不再看。

- 列表最后的 **Default** 规则兜底，处理所有没有命中其他规则的连接。它不能删除，只能修改动作。
- 选中规则后，用右侧的上下箭头调整顺序。越具体的规则越应该放在上面。
- 用 **复制** 复制一条规则再修改。
- 取消规则前的勾选可以暂时停用它。
- 动作可以直接在列表的 **操作** 一栏用下拉框修改，不必打开规则。

双击规则或点 **编辑...** 打开规则窗口：

![规则编辑窗口](/images/rule-edit.png){width=563}

## 条件

一条规则的三个条件同时满足才算命中。留空表示“任意”。多个值用分号分隔。

### 应用程序

程序名、完整路径、文件夹或通配符：

```
chrome.exe; "C:\some app.exe"; C:\Games\; fire*.exe
```

- 只写文件名时，任何位置的同名程序都会命中。
- 写文件夹（以 `\` 结尾）时，这个文件夹里的所有程序都会命中。
- 路径中有空格时要用英文双引号括起来。
- 可以用 **浏览...** 下拉菜单里的 **添加文件...**、**添加文件夹...** 选择，不用手打。

### 目标主机

IP、域名、通配符或 IP 范围：

```
127.0.0.1; *.example.com; 192.168.1.*; 10.1.0.0-10.5.255.255
```

程序按 IP 连接时，WinRoute 会根据之前看到的 DNS 应答还原出域名，所以按域名写的规则同样有效。

### 目标端口

单个端口或范围：

```
80; 443; 8000-9000
```

## 动作

| 动作 | 说明 |
| --- | --- |
| 直接连接 | 不走代理 |
| 阻止 | 拒绝连接 |
| 代理 | 走选定的代理 |
| 代理链 | 走选定的代理链 |

## 指定网卡

在规则窗口点 **高级...**，可以让命中这条规则的连接从某块网卡发出：

![规则网卡](/images/rule-interface.png){width=443}

- 直连时，由这块网卡连接目标；
- 走代理时，由这块网卡连接第一个代理。

适合有多条出口的机器，例如同时有有线网络和 4G，或者公司 VPN。

**网卡断开（未连接）时** 有两个选择：

- **使用系统默认网卡**：照常连接，由系统选择网卡。
- **忽略此规则（由下一条匹配的规则处理）**：适合只在某个网络下才生效的规则。

::: warning
如果所选网卡没有通往目标的路由，连接会失败，而不会悄悄改走别的网卡。域名解析仍然走系统默认路由。
:::

网卡按 GUID 记录，和 Proxifier 4 的“规则网卡”格式相同，两边的配置文件可以互相读取。UDP 转发和代理网关也遵循规则指定的网卡。

## 排查规则

日志会写明每个连接命中的规则名和实际使用的网卡：

```
chrome.exe - www.example.com:443 匹配规则 浏览器：通过代理 203.0.113.10:1080 SOCKS5 连接，网卡 以太网
```

规则不生效时，先看日志里这个连接命中了哪一条。通常是前面一条更宽泛的规则先命中了。

也可以在[连接列表](./main-window#连接)里右键某个连接，选 **为此应用程序创建规则...**，直接为这个程序建规则。
