# 代理规则

菜单：**配置文件 > 代理规则...**，或工具栏中的 **代理规则**。

![代理规则窗口](/images/rules.png){width=863}

## 匹配顺序

每个新连接按自上而下的顺序与规则比对，由 **第一条匹配** 的规则处理，其后的规则不再参与比对。

- 列表末尾的 **Default** 规则处理所有未匹配其他规则的连接。该规则不可删除，仅可修改其操作。
- 选择规则后，使用右侧的上下箭头调整顺序。条件越具体的规则应排列越靠前。
- 单击 **复制** 可复制所选规则。
- 取消勾选规则前的复选框可暂时停用该规则。
- 可直接在列表的 **操作** 列中通过下拉框修改规则的操作。

双击规则或单击 **编辑...** 打开规则窗口：

![规则编辑窗口](/images/rule-edit.png){width=563}

## 条件

规则的三项条件须同时满足才视为匹配。留空表示“任意”。多个值以分号分隔。

### 应用程序

程序名称、完整路径、文件夹或通配符：

```
chrome.exe; "C:\some app.exe"; C:\Games\; fire*.exe
```

- 仅填写文件名时，任意位置的同名程序均匹配。
- 填写文件夹（以 `\` 结尾）时，该文件夹中的所有程序均匹配。
- 路径包含空格时，须用英文双引号括起。
- 可通过 **浏览...** 下拉菜单中的 **添加文件...** 或 **添加文件夹...** 进行选择。

### 目标主机

IP 地址、域名、通配符或 IP 地址范围：

```
127.0.0.1; *.example.com; 192.168.1.*; 10.1.0.0-10.5.255.255
```

应用程序按 IP 地址连接时，WinRoute 会根据此前的 DNS 应答还原对应的域名，因此按域名设置的规则同样有效。

### 目标端口

单个端口或端口范围：

```
80; 443; 8000-9000
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 直接连接 | 不经由代理 |
| 阻止 | 拒绝连接 |
| 代理 | 经由所选代理服务器 |
| 代理链 | 经由所选代理链 |

## 指定网卡

在规则窗口中单击 **高级...**，可使匹配该规则的连接从指定的网络适配器发出：

![规则网卡](/images/rule-interface.png){width=443}

- 直接连接时，由该网卡连接目标主机；
- 经由代理时，由该网卡连接第一个代理服务器。

适用于有多个网络出口的计算机，例如同时连接有线网络和移动网络，或使用企业 VPN 的情况。

**网卡断开（未连接）时** 可选择：

- **使用系统默认网卡**：正常连接，由系统选择网卡。
- **忽略此规则（由下一条匹配的规则处理）**：适用于仅在特定网络环境下生效的规则。

::: warning
如所选网卡没有到达目标的路由，连接将失败，而不会改用其他网卡。域名解析仍使用系统默认路由。
:::

网卡以 GUID 记录，格式与 Proxifier 4 的规则网卡相同，两者的配置文件可相互读取。UDP 转发和代理网关同样遵循规则指定的网卡。

## 规则排查

日志记录每个连接匹配的规则名称和实际使用的网卡：

```
chrome.exe - www.example.com:443 匹配规则 浏览器：通过代理 203.0.113.10:1080 SOCKS5 连接，网卡 以太网
```

如规则未生效，请在日志中确认该连接匹配的规则。常见原因是排列在前的规则条件较宽，先行匹配了该连接。

也可在[连接列表](./main-window#连接)中右键单击连接，选择 **为此应用程序创建规则...**，为该程序新建规则。
