# 域名解析

菜单：**配置文件 > 域名解析...**，或工具栏中的 **域名解析**。

![域名解析窗口](/images/name-resolution.png){width=623}

## 解析方式

### 自动检测 DNS 设置（默认）

本地 DNS 可用时在本地解析；本地 DNS 不可用时，自动改由代理服务器解析。状态栏和日志会显示当前采用的方式。

### 通过代理解析主机名

须先取消勾选 **自动检测 DNS 设置**，才能勾选此项。

应用程序查询域名时，WinRoute 返回 `198.18.0.0/15` 范围内的虚拟 IP 地址。应用程序连接该地址时，WinRoute 将实际域名发送给代理服务器，由其解析。虚拟 IP 地址仅在 WinRoute 运行期间有效。

此方式具有以下作用：

- 本地网络和本地 DNS 服务器无法获知所访问的域名；
- 可访问仅能在代理服务器一侧解析的主机名，例如代理所在内网的主机；
- 代理服务器可解析出距离其较近的服务器地址。

如使用虚拟 IP 地址的连接匹配“直接连接”规则，WinRoute 将先在本地解析，再直接连接。

## 域名列表

可指定仅部分域名由代理服务器解析：

- **不解析以下域名**（默认）：列表中的域名在本地解析，其余由代理解析。默认列表为 `%ComputerName%; localhost; *.local`。
- **只解析以下域名**：仅列表中的域名由代理解析。

列表中可使用 `%ComputerName%`（本机名称）和 `%SimpleHostnames%`（不含点的主机名）。

## 注意事项

- 此功能依赖 DNS 拦截，NetFilter 和 WinDivert 两种后端均支持。
- 使用 DNS over HTTPS 的浏览器不经过系统 DNS，WinRoute 无法获取其查询。如有需要，请在浏览器设置中关闭“安全 DNS”。
- 如需在日志中记录 DNS 查询，请启用[在日志中显示 DNS](./advanced#在日志中显示-dns)。
