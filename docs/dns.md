# 域名解析

菜单：**配置文件 > 域名解析...**，或工具栏的 **域名解析**。

![域名解析窗口](/images/name-resolution.png){width=623}

## 解析方式

### 自动检测 DNS 设置（默认）

本地 DNS 可用时，在本地解析；本地 DNS 不可用时，自动改由代理解析。状态栏和日志会提示当前用的是哪种方式。

### 通过代理解析主机名

要先取消 **自动检测 DNS 设置**，才能勾选这一项。

程序查询域名时，WinRoute 先回一个 `198.18.0.0/15` 范围内的占位地址。程序连接这个地址时，WinRoute 把真实的域名交给代理，由代理解析。

这样做的好处：

- 本地网络和本地 DNS 服务器看不到你访问的域名；
- 能访问只有代理那边才能解析的地址，例如代理所在内网的主机名；
- 代理会解析出离它最近的服务器地址。

如果占位地址的连接命中的是“直接连接”规则，WinRoute 会先在本地解析，再直接连接。

## 域名列表

可以只对部分域名使用代理解析：

- **不解析以下域名**（默认）：列表里的域名仍在本地解析，其余交给代理。默认列表是 `%ComputerName%; localhost; *.local`。
- **只解析以下域名**：只有列表里的域名交给代理解析。

列表里可以用 `%ComputerName%`（本机名）和 `%SimpleHostnames%`（不带点的短主机名）。

## 注意

- 这个功能依赖 DNS 拦截。NetFilter 后端和 WinDivert 后端都支持。
- 使用 DNS over HTTPS 的浏览器会绕过系统 DNS，WinRoute 看不到它的查询。需要时在浏览器设置里关闭“安全 DNS”。
- 想在日志里看到 DNS 查询，开启 [在日志中显示 DNS](./advanced#在日志中显示-dns)。
