# 配置文件

代理、代理链、规则、域名解析和高级选项均保存在配置文件中。配置文件格式与 Proxifier 的 `.ppx` 相同，存放于 `%APPDATA%\WinRoute\Profiles`。

## 文件菜单

| 菜单项 | 功能 |
| --- | --- |
| 新建配置文件 | 创建空白配置文件 |
| 加载配置文件 | 切换到其他配置文件，立即生效 |
| 配置文件另存为... | 将当前配置另存为新文件 |
| 管理配置文件... | 在资源管理器中打开配置文件夹，可重命名或删除配置文件 |
| 导入配置文件... | 从 `.ppx` 文件导入，包括 Proxifier 导出的配置 |
| 导出配置文件... | 导出为 `.ppx` 文件，供其他计算机或 Proxifier 使用 |
| 开机自动启动 | 登录 Windows 时自动启动 WinRoute |
| 关闭 WinRoute 窗口 | 隐藏主窗口，WinRoute 在系统托盘中继续运行 |
| 退出 | 退出 WinRoute 并停止拦截 |

可为不同的网络环境（如家庭、办公室）分别准备配置文件，并随时切换。

## 与 Proxifier 的兼容性

- WinRoute 首次启动时自动导入 Proxifier 4 的默认配置。
- 规则网卡等 Proxifier 4 的设置可相互读取。
- Proxifier 以“basic”方式加密的密码无法解密，导入后须重新输入。

## 开机自动启动

通过以最高权限运行的计划任务实现，因此开机时不显示用户账户控制提示。启动后直接最小化到系统托盘。
