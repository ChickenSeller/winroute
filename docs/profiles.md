# 配置文件

代理、代理链、规则、域名解析和高级选项都保存在配置文件里。配置文件的格式与 Proxifier 的 `.ppx` 相同，存放在 `%APPDATA%\WinRoute\Profiles`。

## 文件菜单

| 菜单项 | 作用 |
| --- | --- |
| 新建配置文件 | 创建一个空白配置 |
| 加载配置文件 | 切换到另一个配置，立即生效 |
| 配置文件另存为... | 把当前配置另存一份 |
| 管理配置文件... | 查看、重命名和删除配置 |
| 导入配置文件... | 从 `.ppx` 文件导入，包括 Proxifier 导出的配置 |
| 导出配置文件... | 导出为 `.ppx` 文件，可以给其他电脑或 Proxifier 使用 |
| 开机自动启动 | 登录 Windows 时自动启动 WinRoute |
| 关闭 WinRoute 窗口 | 隐藏窗口，WinRoute 继续在托盘运行 |
| 退出 | 退出 WinRoute，停止拦截 |

可以为家里、公司等不同环境各准备一份配置，随时切换。

## 与 Proxifier 互通

- WinRoute 第一次启动时会自动导入 Proxifier 4 的默认配置。
- 规则的指定网卡等 Proxifier 4 的设置也能互相读取。
- Proxifier 用“basic”方式加密的密码无法解密，导入后需要重新输入。

## 开机自动启动

通过“最高权限”计划任务实现，所以开机时不会弹出管理员确认框。启动后直接最小化到系统托盘。
