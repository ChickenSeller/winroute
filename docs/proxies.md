# 上游代理

菜单：**配置文件 > 上游代理...**，或工具栏的 **上游代理**。

这里管理 WinRoute 可以使用的代理服务器，以及由它们组成的[代理链](./chains)。

![上游代理窗口](/images/proxies.png){width=563}

## 添加代理服务器

点 **添加...**（或双击已有的代理来编辑），填写：

![代理服务器窗口](/images/proxy-edit.png){width=467}

### 地址和端口

IP 地址或主机名，IPv4 和 IPv6 都可以。

### 协议

| 协议 | 说明 |
| --- | --- |
| SOCKS 版本 5 | 最常用。支持用户名密码认证，也是唯一能转发 UDP 的协议 |
| SOCKS 版本 4 | 勾选“使用 SOCKS 4A 扩展”后，由代理解析主机名 |
| HTTPS | 即支持 CONNECT 隧道的 HTTP 代理，可以转发任何 TCP 连接，支持 Basic 认证 |
| HTTP | 只能用于 HTTP 连接。要先在 **配置文件 > 高级 > HTTP 代理服务器...** 里启用 |

::: warning 不要混淆 HTTP 和 HTTPS
这里的“HTTPS 代理”指支持 CONNECT 的代理，大多数“HTTP 代理”其实都支持 CONNECT，应该选 HTTPS。只有确定代理不支持 CONNECT 时才选 HTTP。
:::

### 身份验证

勾选 **启用** 后填写用户名和密码。NTLM 和 Kerberos 认证暂不支持。

密码在配置文件里如何保存，见[高级选项 › 密码加密](./advanced#密码加密)。

### 检测

保存前可以点 **检测**，用[代理检测](./checker)测试这个代理。

## 高级设置

在代理窗口点 **高级...**：

![代理服务器高级设置](/images/proxy-advanced.png){width=247}

- **自定义标签**：代替默认的“地址:端口”，显示在代理列表、规则和代理检测里，方便区分多个代理。
- **代理请求中尽量使用目标主机名**：把域名而不是 IP 交给代理。适合拒绝裸 IP 的代理，也能让代理端解析出离它最近的地址。

## 设为默认代理

保存新代理时，WinRoute 会询问是否用它作为默认代理。选“是”会把 Default 规则的动作改成这个代理，所有没有命中其他规则的连接都会走它。

## 删除代理

删除一个正被规则使用的代理时，WinRoute 会列出受影响的规则，让你选择：

- 一并删除这些规则；或
- 把它们的动作改成别的代理、代理链、直接连接或阻止。

Default 规则不能删除，只能改动作。
