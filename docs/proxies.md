# 上游代理

菜单：**配置文件 > 上游代理...**，或工具栏中的 **上游代理**。

此窗口用于管理 WinRoute 可使用的代理服务器，以及由其组成的[代理链](./chains)。

![上游代理窗口](/images/proxies.png){width=563}

## 添加代理服务器

单击 **添加...**（或双击已有代理进行编辑），然后设置以下各项。

![代理服务器窗口](/images/proxy-edit.png){width=467}

### 地址和端口

代理服务器的 IP 地址或主机名，支持 IPv4 和 IPv6。

### 协议

| 协议 | 说明 |
| --- | --- |
| SOCKS 版本 5 | 最常用的协议。支持用户名和密码认证，也是唯一支持 UDP 转发的协议 |
| SOCKS 版本 4 | 勾选“使用 SOCKS 4A 扩展”后，主机名由代理服务器解析 |
| HTTPS | 支持 CONNECT 隧道的 HTTP 代理，可转发任意 TCP 连接，支持 Basic 认证 |
| HTTP | 仅可用于 HTTP 连接。须先在 **配置文件 > 高级 > HTTP 代理服务器...** 中启用 |

::: warning HTTP 与 HTTPS 的区别
此处的“HTTPS 代理”指支持 CONNECT 方法的代理服务器。大多数标称为“HTTP 代理”的服务器支持 CONNECT，应选择 HTTPS。仅在确认代理服务器不支持 CONNECT 时选择 HTTP。
:::

### 身份验证

勾选 **启用** 后输入用户名和密码。暂不支持 NTLM 和 Kerberos 认证。

密码在配置文件中的保存方式参见[高级选项 › 密码加密](./advanced#密码加密)。

### 检测

保存前可单击 **检测**，使用[代理检测](./checker)测试该代理服务器。

## 高级设置

在代理服务器窗口中单击 **高级...**：

![代理服务器高级设置](/images/proxy-advanced.png){width=247}

- **自定义标签**：替代默认的“地址:端口”，显示在代理列表、规则和代理检测中，便于区分多个代理。
- **代理请求中尽量使用目标主机名**：向代理服务器发送域名而非 IP 地址。适用于不接受 IP 地址的代理服务器，也可使代理服务器解析出距离其较近的地址。

## 设为默认代理

保存新代理时，WinRoute 会询问是否将其设为默认代理。选择“是”将把 Default 规则的操作改为该代理，所有未匹配其他规则的连接均经由其转发。

## 删除代理

删除正被规则使用的代理时，WinRoute 会列出受影响的规则，并提供以下选择：

- 同时删除这些规则；或
- 将这些规则的操作改为其他代理、代理链、直接连接或阻止。

Default 规则不可删除，仅可修改其操作。
