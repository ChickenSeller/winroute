# 简介

WinRoute 是一款 Windows 网络代理工具。它在系统层面接管应用程序的网络连接，并根据用户设定的规则，将每个连接直接发送、经代理服务器或代理链转发，或予以阻止。应用程序本身无需支持代理，也无需进行任何设置。

WinRoute 的功能和操作方式与 Proxifier 一致，配置文件采用相同的 `.ppx` 格式，可直接导入 Proxifier 的配置。

## 主要功能

| 功能 | 说明 | 参见 |
| --- | --- | --- |
| 规则分流 | 按应用程序、目标主机、IP 范围和端口决定连接的处理方式 | [代理规则](./rules) |
| 多种代理协议 | SOCKS4/4A、SOCKS5（支持 UDP）、HTTPS（CONNECT）、HTTP | [上游代理](./proxies) |
| 代理链 | 简单链、故障切换（冗余）和负载均衡 | [代理链](./chains) |
| 通过代理解析域名 | 域名由代理服务器解析，本地网络无法获知所访问的域名 | [域名解析](./dns) |
| 指定网卡 | 使特定连接从指定的网络适配器发出 | [代理规则](./rules#指定网卡) |
| 连接监控 | 连接列表、流量图、按应用程序统计和日志 | [主窗口](./main-window) |
| 抓包 | 按连接查看 HTTP、DNS 和 UDP 数据，导出为 PCAPNG 或 HAR | [抓包](./capture) |
| HTTPS 解密 | 使用自有根证书解密本机及代理网关设备的 HTTPS 连接 | [解密 HTTPS](./https) |
| 代理网关 | 将本机作为 HTTP/SOCKS5 代理服务器，供局域网内其他设备使用 | [代理网关](./gateway) |

## 系统要求

- Windows 10 1809 或更高版本、Windows 11，仅支持 x64。
- 需要管理员权限。WinRoute 须加载网络驱动才能拦截连接。
- 界面语言：简体中文、日语、英语。

首次使用请参阅[快速上手](./getting-started)。
