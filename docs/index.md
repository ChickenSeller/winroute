# 简介

WinRoute 让 Windows 上的任何程序按你写的规则走代理。很多程序自己没有代理设置，WinRoute 在系统层面接管它们的网络连接，再决定每个连接是直连、走代理、走代理链，还是被阻止。程序本身不需要做任何设置。

WinRoute 的功能和使用方式与 Proxifier 相同，配置文件也是同一种 `.ppx` 格式，可以直接导入 Proxifier 的配置。

## 主要功能

| 功能 | 说明 | 详见 |
| --- | --- | --- |
| 按规则分流 | 按程序、目标主机、IP 范围、端口决定直连、走代理或阻止 | [代理规则](./rules) |
| 多种代理 | SOCKS4/4A、SOCKS5（含 UDP）、HTTPS（CONNECT）、HTTP | [上游代理](./proxies) |
| 代理链 | 简单链、失败切换的冗余链、随机分配的负载均衡 | [代理链](./chains) |
| 通过代理解析域名 | 本地网络看不到访问的域名，按 IP 连接也能按域名分流 | [域名解析](./dns) |
| 指定网卡 | 让某些连接固定从某块网卡发出 | [代理规则](./rules#指定网卡) |
| 实时监控 | 连接列表、流量图、按程序统计、详细日志 | [主窗口](./main-window) |
| 抓包 | 按连接查看 HTTP、DNS、UDP，导出 PCAPNG 和 HAR | [抓包](./capture) |
| 解密 HTTPS | 用自己的根证书解密本机和网关设备的 HTTPS | [解密 HTTPS](./https) |
| 代理网关 | 把本机变成 HTTP/SOCKS5 代理，供局域网其他设备使用 | [代理网关](./gateway) |

## 系统要求

- Windows 10 1809 及以上，或 Windows 11，仅限 x64。
- 需要管理员权限，因为 WinRoute 要加载网络驱动才能拦截连接。
- 界面支持简体中文、日语和英语。

第一次使用请从[快速上手](./getting-started)开始。
