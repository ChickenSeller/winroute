# 日志

主窗口下方的日志记录每个连接的程序、目标、命中的规则、使用的代理和网卡，以及各种错误和提示。

## 日志里有什么

```
chrome.exe - www.example.com:443 匹配规则 浏览器：通过代理 203.0.113.10:1080 SOCKS5 连接，网卡 以太网
git.exe - github.com:443 匹配规则 Default：直接连接，网卡 WLAN
chrome.exe - www.example.com:443 关闭，发送 2372 字节（2.32 KB），接收 5595 字节（5.46 KB），持续 00:10
[Gateway] 192.168.1.20 - www.example.com:443 匹配规则 Default：经由 203.0.113.10:1080，网卡 以太网
```

- **匹配规则 …**：命中的规则名。
- **直接连接 / 通过代理 … 连接 / 通过 代理链 连接**：连接方式。
- **网卡**：实际发出连接的网卡。
- **关闭**：连接结束时记录收发的字节数和持续时间。
- 以 `[Gateway]` 开头的是其他设备经[代理网关](./gateway)的连接。

## 日志菜单

在日志区右键，或使用 **日志** 菜单：

| 菜单项 | 作用 |
| --- | --- |
| 复制、全选、清除 | 操作日志文本 |
| 日志级别 | 调试、详细、普通、仅错误。级别越高记录越多 |
| 写入日志文件 | 把日志另外写入文件，可单独设置级别或关闭 |
| 字体大小 | 调整日志的字体 |

想在日志里看到 DNS 查询，开启 **配置文件 > 高级 > [在日志中显示 DNS](./advanced#在日志中显示-dns)**。
