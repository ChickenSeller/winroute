# 代理检测

菜单：**工具 > 代理检测...**，或工具栏的 **代理检测**。

选择要测试的代理或代理链，填写 **目标主机** 和 **端口**，点 **开始测试**。

## 测试步骤

WinRoute 依次测试，每一步都显示结果和耗时：

1. **连接测试**：能否连上代理服务器。
2. **经代理连接测试**：能否通过代理连上目标主机。
3. **HTTP 请求测试**：通过代理发一个 HTTP 请求，显示响应的状态码。端口是 443 时改做 **TLS 握手测试**。
4. **UDP 支持测试**：只针对 SOCKS5 代理。向代理申请 UDP 中继，再经中继向 `8.8.8.8` 发一个 DNS 查询，收到应答说明这个代理能转发 UDP。

最后显示“代理服务器工作正常”，或在失败的那一步给出原因，例如：

- 认证失败（authentication failed）
- 代理需要认证（proxy requires authentication）
- 10 秒内没有响应
- 不是 SOCKS5 代理
- UDP 中继 5 秒内没有回应（UDP 可能被拦截）

::: tip
添加或编辑代理时，窗口里的 **检测** 按钮也会打开这个工具。
:::
