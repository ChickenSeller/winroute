# はじめに

WinRoute は Windows 用のネットワークプロキシツールです。アプリケーションのネットワーク接続をシステムレベルで引き受け、ユーザーが設定したルールに従って、各接続を直接送信する、プロキシサーバーまたはプロキシチェーン経由で転送する、またはブロックします。アプリケーション自体がプロキシに対応している必要はなく、個別の設定も不要です。

WinRoute の機能と操作方法は Proxifier と同じで、プロファイルも同じ `.ppx` 形式を使用するため、Proxifier のプロファイルをそのままインポートできます。

## 主な機能

| 機能 | 説明 | 参照 |
| --- | --- | --- |
| ルールによる振り分け | アプリケーション、接続先ホスト、IP 範囲、ポートに基づいて接続の処理方法を決定 | [プロキシ化ルール](./rules) |
| 各種プロキシプロトコル | SOCKS4/4A、SOCKS5（UDP 対応）、HTTPS（CONNECT）、HTTP | [上流プロキシ](./proxies) |
| プロキシチェーン | シンプルチェーン、冗長化（フェイルオーバー）、負荷分散 | [プロキシチェーン](./chains) |
| プロキシ経由の名前解決 | ホスト名をプロキシサーバーで解決し、ローカルネットワークにアクセス先を知られないようにする | [名前解決](./dns) |
| ルールごとのネットワークインターフェイス | 特定の接続を指定したネットワークアダプターから送信 | [プロキシ化ルール](./rules#ネットワークインターフェイスの指定) |
| 接続の監視 | 接続一覧、トラフィックグラフ、アプリケーション別の統計、ログ | [メインウィンドウ](./main-window) |
| パケットキャプチャ | 接続ごとに HTTP、DNS、UDP のデータを表示し、PCAPNG または HAR にエクスポート | [パケットキャプチャ](./capture) |
| HTTPS の復号 | 独自のルート証明書で、このコンピューターとプロキシゲートウェイ利用端末の HTTPS を復号 | [HTTPS の復号](./https) |
| プロキシゲートウェイ | このコンピューターを HTTP/SOCKS5 プロキシサーバーとして、ネットワーク上の他の端末に提供 | [プロキシゲートウェイ](./gateway) |

## システム要件

- Windows 10 バージョン 1809 以降、または Windows 11（x64 のみ）。
- 管理者権限。WinRoute は接続を捕捉するためにネットワークドライバーを読み込みます。
- 表示言語：日本語、英語、簡体字中国語。

初めて使用する場合は、[クイックスタート](./getting-started)を参照してください。
