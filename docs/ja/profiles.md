# プロファイル

プロキシ、チェーン、ルール、名前解決、詳細設定はプロファイルに保存されます。プロファイルは Proxifier と同じ `.ppx` 形式で、`%APPDATA%\WinRoute\Profiles` に保存されます。

## ファイルメニュー

| コマンド | 機能 |
| --- | --- |
| 新しいプロファイル | 空のプロファイルを作成します |
| プロファイルの読み込み | 別のプロファイルに切り替えます。すぐに有効になります |
| 名前を付けてプロファイルを保存... | 現在のプロファイルを別の名前で保存します |
| プロファイルの管理... | エクスプローラーでプロファイルのフォルダーを開きます。プロファイルの名前の変更や削除ができます |
| プロファイルのインポート... | `.ppx` ファイルをインポートします。Proxifier からエクスポートしたプロファイルにも対応しています |
| プロファイルのエクスポート... | `.ppx` ファイルにエクスポートし、他のコンピューターや Proxifier で使用できるようにします |
| 自動起動 | Windows へのサインイン時に WinRoute を自動的に起動します |
| WinRoute ウィンドウを閉じる | メインウィンドウを非表示にします。WinRoute はシステムトレイで動作を続けます |
| 終了 | WinRoute を終了し、捕捉を停止します |

自宅やオフィスなど、ネットワーク環境ごとにプロファイルを用意し、いつでも切り替えることができます。

## Proxifier との互換性

- WinRoute は初回起動時に Proxifier 4 の既定のプロファイルを自動的にインポートします。
- ルールのネットワークインターフェイスなど、Proxifier 4 の設定は相互に読み込めます。
- Proxifier が「basic」方式で暗号化したパスワードは復号できないため、インポート後に再入力する必要があります。

## 自動起動

最上位の特権で実行されるタスクスケジューラのタスクとして実装されているため、サインイン時にユーザーアカウント制御の確認は表示されません。起動後はシステムトレイに最小化されます。
