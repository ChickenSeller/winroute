# メインウィンドウ

メインウィンドウの上部にはいくつかのタブがあり、下部には[ログ](./log)が表示されます。

## ツールバー

| ボタン | 機能 |
| --- | --- |
| 上流プロキシ | プロキシサーバーとプロキシチェーンを管理します。[上流プロキシ](./proxies)を参照 |
| プロキシ化ルール | ルールを編集します。[プロキシ化ルール](./rules)を参照 |
| 名前解決 | ホスト名をローカルで解決するか、プロキシで解決するかを設定します。[名前解決](./dns)を参照 |
| プロキシゲートウェイ | 他の端末がこのコンピューター経由でネットワークにアクセスできるようにします。[プロキシゲートウェイ](./gateway)を参照 |
| 切断 | 選択した接続を閉じます |
| プロセスの終了 | 選択した接続を所有するプロセスを終了します |
| プロキシチェッカー | プロキシサーバーが利用できるかをテストします。[プロキシチェッカー](./checker)を参照 |
| パケットキャプチャ | キャプチャタブを開きます。[パケットキャプチャ](./capture)を参照 |

## 接続

WinRoute を経由している現在のすべての接続を表示します。列見出しをクリックすると並べ替えられます。

![接続一覧](/images/ja/connections.png){width=1347}

上の画面では、curl.exe が「コマンドラインツール」ルールに一致し、ローカルのプロキシクライアント（127.0.0.1:10808）経由で接続しています。プロキシクライアントである python.exe 自身の接続は、[接続ループの検出](./advanced#接続ループの検出)により自動的に直接接続になっています。

| 列 | 内容 |
| --- | --- |
| アプリケーション | プログラム名とプロセス ID |
| 接続先 | 接続先のホストとポート。アプリケーションが IP アドレスで接続した場合も、可能な限り対応するホスト名を表示します |
| プロトコル | TCP または UDP、および IPv4 または IPv6 |
| 時間/状態 | 接続の継続時間、または接続中・失敗などの状態 |
| ルール : プロキシ | 一致したルールと、使用しているプロキシのアドレスまたはチェーン |
| 送信 / 受信 | データ量 |

プロキシゲートウェイの実行中は、他の端末がゲートウェイ経由で行った接続も表示され、アプリケーション列は `[Gateway] 端末の IP` となります。

接続を右クリックすると、次の操作を実行できます。

- **切断**：接続をすぐに閉じます。
- **プロセスの終了**：接続を開いたプロセスを、確認の後に終了します。WinRoute はまずそのプロセスのウィンドウを閉じ、ユーザーが閉じたときと同様に正常に終了させます。5 秒以内に終了しない場合、またはウィンドウがない場合は強制終了します。
- **このアプリケーションのルールを作成...**：このアプリケーションを条件とする新しいルールを作成します。
- **コピー**：接続の情報をコピーします。

::: info 直接接続が表示されない理由
既定では、**直接接続** ルールに一致した接続は WinRoute を経由しないため、一覧に表示されません。表示するには、[直接接続を処理する](./advanced#直接接続を処理する)を有効にしてください。
:::

## トラフィック

![トラフィックグラフ](/images/ja/traffic.png){width=1347}

リアルタイムのトラフィック曲線を表示します。

- このコンピューターの受信速度と送信速度をそれぞれ 1 本の曲線で表示します。
- プロキシゲートウェイの実行中は、ゲートウェイの受信速度と送信速度の曲線も表示します。

グラフ上部の凡例はグループごとに並び、各グループで受信が上、送信が下に表示され、現在の速度とクリア以降の最高速度を示します。凡例をクリックすると、対応する曲線の表示・非表示を切り替えられます。**クリア** をクリックすると、グラフを消去して合計を最初から集計し直します。

## 統計

アプリケーションと接続先ごとに、接続数、アクティブな接続数、送信量、受信量、最終アクティビティの時刻を集計し、通信量の多いアプリケーションを把握できます。右クリックで **コピー** または **統計のリセット** を実行できます。

## キャプチャ

**ツール > パケットキャプチャ** を有効にすると、このタブが表示されます。[パケットキャプチャ](./capture)を参照してください。

## ステータスバー

アクティブな接続数、現在の速度、捕捉方式、ドライバーの状態、現在のプロファイルを表示します。
