# ログ

メインウィンドウ下部のログには、各接続のアプリケーション、接続先、一致したルール、使用したプロキシとネットワークアダプター、およびエラーや通知が記録されます。

## ログの内容

```
chrome.exe - www.example.com:443 ルール ブラウザー に一致：プロキシ 203.0.113.10:1080 SOCKS5 経由で接続、アダプター イーサネット
git.exe - github.com:443 ルール Default に一致：直接接続、アダプター Wi-Fi
chrome.exe - www.example.com:443 切断、送信 2372 バイト（2.32 KB）、受信 5595 バイト（5.46 KB）、接続時間 00:10
[Gateway] 192.168.1.20 - www.example.com:443 ルール Default に一致：203.0.113.10:1080 経由、アダプター イーサネット
```

- **ルール … に一致**：一致したルールの名前。
- **直接接続 / プロキシ … 経由で接続 / チェーン経由で接続**：接続方法。
- **アダプター**：実際に接続に使用したネットワークアダプター。
- **切断**：接続の終了時に、送受信したバイト数と継続時間を記録します。
- `[Gateway]` で始まる記録は、他の端末が[プロキシゲートウェイ](./gateway)経由で行った接続です。

## ログメニュー

ログ領域を右クリックするか、**ログ** メニューを使用します。

| コマンド | 機能 |
| --- | --- |
| コピー、すべて選択、クリア | ログのテキストを操作します |
| ログレベル | デバッグ、詳細、標準、エラーのみ。詳細なレベルほど多く記録されます |
| ファイルにログを記録 | ログをファイルにも書き込みます。レベルを個別に設定するか、無効にできます |
| フォントサイズ | ログのフォントサイズを変更します |

DNS の照会をログに記録するには、**プロファイル > 詳細設定 > [DNS をログに表示](./advanced#dns-をログに表示)** を有効にしてください。
