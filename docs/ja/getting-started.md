# クイックスタート

## 1. インストール

[リリースページ](https://pages.yanlei.org/kaguya/winroute/releases.html)から最新のインストーラーをダウンロードして実行します。ドライバーは既定の選択のままで問題ありません。各ドライバーの違いについては[インストールとネットワークドライバー](./install)を参照してください。

インストールが完了したら WinRoute を起動します。管理者権限が必要なため、起動時に Windows のユーザーアカウント制御の確認が表示されます。

::: tip Proxifier からの移行
初回起動時に、WinRoute は `%APPDATA%\Proxifier4\Profiles\Default.ppx` を自動的にインポートするため、既存のプロキシとルールをそのまま使用できます。Proxifier と WinRoute はどちらもネットワーク接続を捕捉するため、同時に実行しないでください。
:::

## 2. プロキシサーバーの追加

1. ツールバーの **上流プロキシ** をクリックし、**追加...** をクリックします。
2. プロキシサーバーの **アドレス** と **ポート** を入力し、**プロトコル** を選択します（多くのプロキシサーバーは SOCKS5 です）。認証が必要な場合は、**認証** の **有効** をオンにし、ユーザー名とパスワードを入力します。
3. 必要に応じて **チェック** をクリックし、プロキシサーバーが利用できることを確認します。
4. **OK** をクリックします。既定のプロキシとして使用するかどうかを確認するメッセージが表示されます。
   - **はい**：他のルールに一致しないすべての接続がこのプロキシを経由します。
   - **いいえ**：ルールでこのプロキシを指定した接続のみが経由します。

## 3. ルールの作成（任意）

一部のアプリケーションのみプロキシを使用する場合：

1. ツールバーの **プロキシ化ルール** をクリックし、**追加...** をクリックします。
2. **名前** にルール名（例：「ブラウザー」）を入力します。
3. **アプリケーション** に `chrome.exe; msedge.exe` と入力します。
4. **アクション** で前の手順で追加したプロキシを選択し、**OK** をクリックします。
5. 一覧の末尾にある **Default** ルールのアクションを **直接接続** に設定すると、その他のアプリケーションは直接接続します。

ルールの詳細については[プロキシ化ルール](./rules)を参照してください。

## 4. 動作の確認

- メインウィンドウの **接続** タブに、各接続と一致したルール、使用中のプロキシがリアルタイムで表示されます。
- ウィンドウ下部のログに、各接続の処理内容が記録されます。例：

```
chrome.exe - www.example.com:443 ルール ブラウザー に一致：プロキシ 203.0.113.10:1080 SOCKS5 経由で接続、アダプター イーサネット
```

ルールが期待どおりに機能しない場合は、まずログでその接続が一致したルールを確認してください。
