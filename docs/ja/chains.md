# プロキシチェーン

プロキシチェーンは **上流プロキシ** ウィンドウの下半分で管理します。

## プロキシチェーンの作成

1. **作成** をクリックし、チェーンの名前を入力します。
2. 上の一覧からプロキシをチェーンに **ドラッグ** します。チェーン内の順序が使用順序となり、チェーン内でドラッグして順序を変更できます。
3. チェーン内のプロキシの前にあるチェックボックスをオフにすると、そのプロキシを一時的に無効にできます。
4. チェーンを選択し、**種類...** をクリックして動作方式を設定します。

![上流プロキシウィンドウ下半分のプロキシチェーン](/images/ja/proxies.png){width=584}

作成したチェーンは、単一のプロキシと同様に[ルール](./rules)のアクションとして使用できます。

## チェーンの種類

![チェーンの種類](/images/ja/chain-type.png){width=511}

### シンプルチェーン

接続はチェーン内のすべてのプロキシを順に経由します。最初のプロキシに接続し、それを経由して 2 番目のプロキシに接続し、以下同様に続けて、最後のプロキシが接続先ホストに接続します。多段の中継が必要な場合に使用します。

### 冗長化

最初のプロキシを使用し、失敗した場合は次のプロキシを使用します。**オプション...** をクリックすると、次の項目を設定できます。

![冗長化オプション](/images/ja/redundancy.png){width=380}

| オプション | 説明 |
| --- | --- |
| プロキシへの接続タイムアウト（秒） | プロキシへの接続を待つ時間。超えた場合は失敗とみなします |
| 失敗したプロキシの再確認間隔（秒） | 失敗したプロキシはこの期間スキップされ、その後に再試行されます |
| すべてのプロキシが失敗した場合は直接接続する | オフの場合は接続が失敗し、オンの場合は直接接続します |
| すべてのプロキシの失敗状態をリセット | 失敗したプロキシをただちに使用対象に戻します |

### 負荷分散

接続ごとにプロキシを無作為に選択します。

**同じプロセス PID には同じプロキシを使用する** をオンにすると、同じプロセスの接続には常に同じプロキシが使用されます。送信元 IP アドレスが変わると再ログインを求めるウェブサイトがあるため、このオプションでそれを避けられます。

::: info
プロキシチェーンは TCP のみを転送します。UDP は単一の SOCKS5 プロキシ経由でのみ転送でき、チェーンに一致した UDP 通信は直接送信され、ログに一度通知されます。
:::
