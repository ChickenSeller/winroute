# インストールとネットワークドライバー

## インストール

インストーラーを実行します。デスクトップショートカットの作成と、ログオン時の自動起動を選択できます。インストーラーは日本語、英語、簡体字中国語に対応しています。WinRoute の実行中は、インストールおよびアンインストールの前に終了するよう求められます。

### ドライバーの選択

インストーラーの「ネットワークドライバー」ページで、接続の捕捉に使用するドライバーを選択します。

| ドライバー | 説明 |
| --- | --- |
| NetFilter SDK デモドライバー（既定） | すべての機能を使用できますが、捕捉できる接続の総数に上限があります。上限に達した場合は Windows の再起動が必要です |
| ドライバー A / ドライバー B | 製品版ドライバーで、接続数の上限はありません。一方が不安定な場合は、もう一方を使用してください |

アップグレード時は前回の選択が引き継がれます。インストール後も、下記のとおりアプリケーション内でいつでも変更できます。

### サイレントインストール

```
WinRoute-x.y.z-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /TASKS=autostart /DRIVER=a
```

- `/TASKS=autostart`：自動起動タスクを作成します。
- `/DRIVER=demo|a|b`：ドライバーを指定します。省略した場合、新規インストールではデモドライバー、アップグレードでは前回の選択が使用されます。

## 捕捉方式とドライバーの変更

メニュー：**ツール > ネットワークドライバー...**

WinRoute には 2 種類の捕捉方式（バックエンド）があり、再インストールせずにいつでも切り替えられます。

### NetFilter（推奨）

WFP ドライバーを使用し、アプリケーションが接続を開始する時点で接続先を書き換えます。UDP の転送やプロキシ経由の名前解決を含め、すべての機能に対応しています。

このウィンドウで、デモドライバーとドライバー A/B のインストール、切り替え、アンインストールができます。切り替え時は、捕捉を停止してドライバーファイルを置き換えた後、捕捉を再開します。通常は数秒で完了します。

### WinDivert

パケットレベルで TCP と UDP を捕捉し、選択するとすぐに有効になります。初回起動時にカーネルサービスが自動的にインストールされます。NetFilter ドライバーを読み込めない環境で使用します。このウィンドウで WinDivert サービスをアンインストールすることもできます。

::: tip
メインウィンドウ下部のステータスバーに、現在の捕捉方式、ドライバー、その動作状態が表示されます。ドライバーの署名をクリックすると、署名証明書の詳細を確認できます。
:::

## アンインストール

Windows の **設定 > アプリ** からアンインストールします。アンインストーラーは次の処理を行います。

1. 自動起動タスクを削除します。
2. ネットワークドライバーを停止して削除します。
3. プロファイル、設定、ログを削除するかどうかを確認します（サイレントアンインストールの場合は保持されます）。
