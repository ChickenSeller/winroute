# 表示、トレイ、更新

## 表示メニュー

| コマンド | 機能 |
| --- | --- |
| ツールバー、ステータスバー | 表示・非表示を切り替えます |
| 更新間隔 | 接続一覧とトラフィックグラフの更新頻度。頻度が低いほどリソースの消費が少なくなります |
| システムトレイにアイコンを表示 | 下記を参照 |
| 言語 | 日本語、English、简体中文。既定ではシステムの設定に従います。変更後は再起動が必要です |

## システムトレイ

**システムトレイにアイコンを表示** を有効にした場合：

- メインウィンドウを閉じてもシステムトレイに隠れるだけで、WinRoute は動作を続けます。
- トレイアイコンのツールチップに、現在のプロファイル、アクティブな接続数、速度が表示されます。
- トレイメニューからメインウィンドウを開いたり、WinRoute を終了したりできます。

WinRoute を終了するには、**ファイル > 終了** またはトレイメニューの終了コマンドを使用します。

## 更新

**ヘルプ** メニューには、次の更新関連のコマンドがあります。

| コマンド | 機能 |
| --- | --- |
| 更新の確認... | 新しいバージョンをすぐに確認します。確認後、ダウンロード、検証、インストールを行い、WinRoute を再起動します |
| プロキシ経由で更新を確認... | 更新サーバーに直接接続できない場合に、プロファイルのプロキシを使用して確認とダウンロードを行います |
| 自動更新 | すべての更新を自動でインストール、必須の更新を自動でインストール、更新前に確認、確認しない、から選択します |
| 自動更新 > プロキシ経由で確認 | 自動更新の確認とダウンロードを、直接接続ではなくプロキシ経由で行います。更新サーバーに直接接続できないネットワーク向けです。使用するプロキシはプロファイルの既定の DNS プロキシ、未設定の場合は最初のプロキシです |

ダウンロードしたインストーラーは SHA-256 で検証され、検証に失敗したファイルはインストールされません。

## 匿名の使用統計

**ヘルプ > 匿名の使用統計を送信**：WinRoute の改善に役立てられます。個人データは含まれず、いつでも無効にできます。

## バージョン情報

**ヘルプ > WinRoute について...** でバージョン情報を表示します。
