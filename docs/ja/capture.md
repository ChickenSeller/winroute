# パケットキャプチャ

メニュー：**ツール > パケットキャプチャ**。有効にすると、メインウィンドウに **キャプチャ** タブが表示されます。

パケットキャプチャは、WinRoute を経由する接続が送受信するアプリケーション層のデータを記録し、アプリケーションのネットワーク動作の分析に使用します。記録したデータはこのコンピューターのメモリ上にのみ保持され、アップロードされることはありません。

![キャプチャタブ](/images/ja/capture.png){width=1347}

初めてキャプチャを開始すると、キャプチャしたデータはこのコンピューターにのみ保存されること、HTTPS の復号を有効にするとパスワードなどの機密情報が含まれる場合があるため、エクスポートや共有の際は注意が必要であることが表示されます。

## ツールバー

| コントロール | 機能 |
| --- | --- |
| 開始 / 一時停止 | 記録を開始または一時停止します |
| クリア | 記録したデータを破棄します |
| エクスポート... | PCAPNG または HAR にエクスポートします。下記を参照 |
| フィルター... | 記録する接続を設定します。下記を参照 |
| キャプチャ：このコンピューター | このコンピューターのアプリケーションの接続を記録します |
| キャプチャ：プロキシゲートウェイ | 他の端末が[プロキシゲートウェイ](./gateway)経由で行った接続を記録します。ゲートウェイが無効な間は使用できません |
| HTTPS を復号 | このコンピューターとプロキシゲートウェイについて、個別に HTTPS の復号を有効にします。[HTTPS の復号](./https)を参照 |
| ルート証明書... | 復号に使用するルート証明書を管理します |

## フィルター

**フィルター...** をクリックし、記録する範囲を選択します。

![キャプチャフィルター](/images/ja/capture-filter.png){width=563}

- **すべて**
- **ルールに一致する接続のみ（ホワイトリスト）**
- **ルールに一致する接続以外すべて（ブラックリスト）**

ホワイトリストまたはブラックリストの場合は、**追加...** をクリックしてフィルタールールを追加します。ルールはアプリケーション、接続先ホスト、ポートで指定し、構文は[プロキシ化ルール](./rules#条件)と同じです。入力したすべての項目が一致した場合にルールに一致し、空欄の項目は制限されません。たとえば、特定のアプリケーションのみを記録したり、証明書のピン留めを行うアプリケーションを除外したりできます。

![キャプチャルール](/images/ja/capture-rule.png){width=450}

## 記録される内容

一覧の各行が 1 つの接続に対応し、選択すると右側に詳細が表示されます。

### HTTP

HTTP/1.x は要求と応答に解析され、メソッド、URL、ステータスコード、ヘッダー、本文が表示されます。復号を有効にすると、HTTPS 接続も同様に表示されます。プロトコル列に鍵のアイコンがある行が、復号された接続です。

### その他の TCP

送信方向ごとに区切り、16 進数とテキストを並べて表示します。

### DNS

両方の捕捉方式で取得した DNS の照会と応答は、プロセス、ローカルポート、DNS サーバーごとに 1 行にまとめられます。接続先は「照会名 @ サーバー」と表示され、詳細には質問、応答コード、レコードが解読されて表示されます。フィルタールールは照会したホスト名と照合されます。

[プロキシ経由でホスト名を解決する](./dns#プロキシ経由でホスト名を解決する)が有効な場合、アプリケーションが受け取るのは WinRoute が返す仮のアドレスの応答で、状態列には「ローカルで応答」と表示されます。実際の名前解決はプロキシ側で行われるため、このコンピューターでは記録できません。

### UDP

SOCKS5 経由で転送した UDP は、プロセスと接続先ごとに 1 行にまとめられ、送受信した各データグラムが記録されます。

### 記録されないもの

- [直接接続を処理する](./advanced#直接接続を処理する)が無効な場合の、直接接続の TCP
- プロキシ経由で転送されない UDP
- WinRoute 自身の接続と DNS 照会

## エクスポート

**エクスポート...** をクリックすると、最初にオプションのダイアログが表示されます。

![キャプチャのエクスポート](/images/ja/capture-export.png){width=554}

- **範囲**：既定ではすべての接続をエクスポートします。選択した接続のみをエクスポートするには、該当するオプションをオンにしてください。一覧で行を選択しただけでは、エクスポートの範囲は狭まりません。
- **形式**（保存ダイアログで選択）：
  - **PCAPNG**：Wireshark 用です。TCP 接続はハンドシェイクとセグメントを合成して書き込まれ、Wireshark でストリームとして再構成できます。UDP と DNS は実際の UDP パケットとして書き込まれます。
  - **HAR**：HTTP のやり取りのみを含みます。ブラウザーの開発者ツールなどにインポートできます。

### 復号した HTTPS の Wireshark での表示

| オプション | 効果 |
| --- | --- |
| 実際のポート（443）を保持（既定） | Wireshark でそのポートに「Decode As → HTTP」を設定する必要があります。設定しない場合は TLS として解析され、正しく表示されません |
| ポート 80 を使い、Wireshark が自動で HTTP 表示 | Wireshark が自動的に HTTP として解析します |
| 実際のポート（443）を保持し自動で HTTP 表示 | Exported PDU 形式で書き込まれ、ポートは 443 のまま Decode As が不要です。ただし TCP ストリーム表示はなく、1 パケットの上限は 256 KB です |
