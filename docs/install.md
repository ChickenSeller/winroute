# 安装与网络驱动

## 安装

运行安装程序，可选择创建桌面快捷方式和开机自动启动。安装程序支持简体中文、日语和英语。如 WinRoute 正在运行，安装和卸载前会提示先将其关闭。

### 选择驱动

安装程序的“网络驱动”页用于选择拦截连接所用的驱动：

| 驱动 | 说明 |
| --- | --- |
| NetFilter SDK 演示驱动（默认） | 功能完整，但可拦截的连接总数有上限。达到上限后，须重新启动 Windows 才能恢复 |
| 驱动 A / 驱动 B | 正式版驱动，无连接数限制。如某一驱动在当前系统上运行不稳定，可改用另一驱动 |

升级安装时沿用上次的选择。安装后也可在程序中随时切换，参见下文。

### 静默安装

```
WinRoute-x.y.z-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /TASKS=autostart /DRIVER=a
```

- `/TASKS=autostart`：创建开机自动启动任务。
- `/DRIVER=demo|a|b`：指定驱动。未指定时，首次安装使用演示驱动，升级安装沿用上次的选择。

## 切换拦截后端和驱动

菜单：**工具 > 网络驱动...**

WinRoute 提供两种拦截后端，可随时切换，无需重新安装。

### NetFilter（推荐）

基于 WFP 驱动，在应用程序发起连接时改写目标地址。支持 UDP 转发、通过代理解析主机名等全部功能。

在此窗口中可安装、切换或卸载演示驱动及驱动 A/B。切换时，WinRoute 先停止拦截并替换驱动文件，然后重新启动拦截，通常在数秒内完成。

### WinDivert

在数据包层面拦截 TCP 和 UDP，选择后立即生效。首次启动时会自动安装其内核服务。适用于无法加载 NetFilter 驱动的环境。在此窗口中也可卸载 WinDivert 服务。

::: tip
主窗口底部的状态栏显示当前的拦截后端、驱动及其运行状态。单击驱动签名可查看签名证书的详细信息。
:::

## 卸载

通过 Windows 的“应用”设置卸载。卸载程序将：

1. 删除开机自动启动任务；
2. 停止并删除网络驱动；
3. 询问是否同时删除配置文件、设置和日志（静默卸载时予以保留）。
