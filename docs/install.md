# 安装与网络驱动

## 安装

运行安装包，可以选择创建桌面快捷方式和开机自动启动。安装程序支持中文、日语和英语界面。WinRoute 正在运行时，安装和卸载前都会提示先关闭它。

### 选择驱动

安装程序的“网络驱动”页用来选择拦截连接用的驱动：

| 驱动 | 说明 |
| --- | --- |
| NetFilter SDK 演示驱动（默认） | 功能完整，但拦截的连接总数有上限，达到上限后要重启 Windows 才能恢复 |
| 驱动 A / 驱动 B | 正式版驱动，没有连接数限制。某个驱动在你的系统上不稳定时，可以换另一个 |

升级安装时沿用上次的选择。装好后也可以随时在程序里切换，见下文。

### 静默安装

```
WinRoute-x.y.z-setup.exe /VERYSILENT /SUPPRESSMSGBOXES /TASKS=autostart /DRIVER=a
```

- `/TASKS=autostart`：创建开机自启动任务。
- `/DRIVER=demo|a|b`：选择驱动。不写时，首次安装用演示驱动，升级时沿用上次的选择。

## 切换拦截后端和驱动

菜单：**工具 > 网络驱动...**

WinRoute 有两种拦截方式，可以随时切换，不需要重装：

### NetFilter（推荐）

基于 WFP 驱动，在程序发起连接时改写目标地址。支持 UDP 转发、通过代理解析主机名等全部功能。

在这个窗口里可以安装、切换或卸载演示驱动和驱动 A/B。切换时 WinRoute 会先停止拦截、替换驱动文件，再重新启动，通常一两秒就能完成。

### WinDivert

在数据包层面拦截 TCP 和 UDP，选中即生效。第一次启动时它会自动安装自己的内核服务。适合 NetFilter 驱动无法加载的环境。这个窗口里也可以卸载 WinDivert 服务。

::: tip
主窗口底部的状态栏显示当前的后端、驱动以及它是否在运行。点驱动签名可以查看签名证书的详情。
:::

## 卸载

在 Windows 的“应用和功能”里卸载。卸载程序会：

1. 删除开机自启动任务；
2. 停止并删除网络驱动；
3. 询问是否同时删除配置文件、设置和日志（静默卸载时保留）。
