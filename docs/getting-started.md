# 快速上手

## 1. 安装

从[版本页面](https://pages.yanlei.org/kaguya/winroute/releases.html)下载最新的安装程序并运行。驱动选项保持默认即可，各驱动的区别参见[安装与网络驱动](./install)。

安装完成后启动 WinRoute。程序需要管理员权限，启动时 Windows 会显示用户账户控制提示。

::: tip 从 Proxifier 迁移
首次启动时，WinRoute 会自动导入 `%APPDATA%\Proxifier4\Profiles\Default.ppx`，原有的代理和规则可直接使用。Proxifier 与 WinRoute 均会拦截网络连接，请勿同时运行。
:::

## 2. 添加代理服务器

1. 单击工具栏中的 **上游代理**，然后单击 **添加...**。
2. 输入代理服务器的 **地址** 和 **端口**，并选择 **协议**（多数代理服务器使用 SOCKS5）。如代理服务器需要认证，请在 **身份验证** 中勾选 **启用**，并输入用户名和密码。
3. 可单击 **检测** 确认代理服务器是否可用。
4. 单击 **确定**。WinRoute 会询问是否将其设为默认代理：
   - 选择“是”：所有未匹配其他规则的连接均经由该代理转发。
   - 选择“否”：仅在规则中指定该代理的连接经由其转发。

## 3. 创建规则（可选）

如只需部分应用程序使用代理：

1. 单击工具栏中的 **代理规则**，然后单击 **添加...**。
2. 在 **名称** 中输入规则名称，例如“浏览器”。
3. 在 **应用程序** 中输入 `chrome.exe; msedge.exe`。
4. 在 **操作** 中选择上一步添加的代理，然后单击 **确定**。
5. 将列表末尾 **Default** 规则的操作设为 **直接连接**，其他应用程序即直接连接。

规则的详细说明参见[代理规则](./rules)。

## 4. 确认运行状态

- 主窗口的 **连接** 页实时列出各连接及其匹配的规则和所用代理。
- 窗口下方的日志记录每个连接的处理方式，例如：

```
chrome.exe - www.example.com:443 匹配规则 浏览器：通过代理 203.0.113.10:1080 SOCKS5 连接，网卡 以太网
```

如规则未按预期生效，请首先在日志中确认该连接匹配的规则。
