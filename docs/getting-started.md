# 快速上手

## 1. 安装

从[版本页面](https://pages.yanlei.org/kaguya/winroute/releases.html)下载最新的安装包并运行。安装时保持默认的驱动选项即可，各个驱动的区别见[安装与网络驱动](./install)。

安装完成后启动 WinRoute。它需要管理员权限，启动时 Windows 会弹出确认框。

::: tip 用过 Proxifier？
第一次启动时，WinRoute 会自动导入 `%APPDATA%\Proxifier4\Profiles\Default.ppx`，原有的代理和规则直接可用。Proxifier 和 WinRoute 都会拦截连接，不要同时运行。
:::

## 2. 添加代理

1. 点工具栏的 **上游代理**，再点 **添加...**。
2. 填写代理服务器的 **地址**、**端口**，选择 **协议**（大多数代理是 SOCKS5）。代理需要账号时，在 **身份验证** 里勾选 **启用** 并填写用户名和密码。
3. 可以先点 **检测**，确认代理能用。
4. 点 **确定**。WinRoute 会询问是否把它设为默认代理：
   - 选“是”：所有没有命中其他规则的连接都走这个代理，也就是“全局代理”。
   - 选“否”：只有你在规则里指定了这个代理的连接才会走它。

## 3. 写规则（可选）

只想让部分程序走代理时：

1. 点工具栏的 **代理规则**，点 **添加...**。
2. **名称** 随意，例如“浏览器”。
3. **应用程序** 填 `chrome.exe; msedge.exe`。
4. **动作** 选刚才添加的代理，点 **确定**。
5. 把最下面的 **Default** 规则的动作改成 **直接连接**，其他程序就会直连。

规则的完整写法见[代理规则](./rules)。

## 4. 查看效果

- 主窗口的 **连接** 页实时列出每个连接，以及它命中的规则和使用的代理。
- 窗口下方的日志会写明每个连接的去向，例如：

```
chrome.exe - www.example.com:443 匹配规则 浏览器：通过代理 203.0.113.10:1080 SOCKS5 连接，网卡 以太网
```

规则没按预期生效时，先看日志里这个连接命中了哪条规则。
